# Student REST API

## Features

- POST
- GET ALL
- GET BY ID
- PUT
- PATCH
- DELETE
- Validation
- Error Handling
- Swagger Documentation

## Install

```bash
pip install -r requirements.txt
```

## Seed Data

```bash
python seed_data.py
```

## Run

```bash
uvicorn main:app --reload
```

Swagger

```
http://127.0.0.1:8000/docs
```
